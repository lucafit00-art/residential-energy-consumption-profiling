# Residential Energy Consumption Profiling
MATLAB code developed for the analysis and profiling of residential electricity consumption habits.
This repository contains the code developed as part of the Bachelor's thesis:

**"Analisi e profilazione delle abitudini di consumo elettrico di utenti residenziali"**
at Università Politecnica delle Marche (UNIVPM).

## Repository contents
- `UTENTE1.m` – MATLAB script used for the analysis and profiling of the first residential user.
- `UTENTE2.m` – MATLAB script used for the application of the methodology to the second residential user.

## Data availability
The datasets used in this work are not included in this repository because they are private.
Therefore, the scripts cannot be executed directly without access to the original datasets and their corresponding data structure.

## Software
The analysis was developed using MATLAB.
